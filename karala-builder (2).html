    Welcome to Karala Builder

    by Okan Kaplan

    Draw on a paper-style canvas — get a real, publish-ready Bootstrap page. No coding needed.

    1. Draw simple shapes where you want each part: a thin bar = menu, a roof = hero section, boxes = cards, a circle = avatar, a star = features, a wave = divider.
    2. Build — press Build My Page; every stroke becomes an editable block with clean code.
    3. Edit — click any block in the left list to change text, links and settings. Watch the live preview.
    4. Publish — in the code panel: Download HTML to host anywhere, or PDF / Print → “Save as PDF”.

    The guided tour highlights every control with an orange dotted arrow and speaks each step aloud in English. Mute anytime with the speaker button in the top bar.
